ℹ️ About This Project

This system is a machine learning-based final year project designed to address the growing concern of smartphone addiction. It demonstrates the practical application of supervised learning for behavioral analysis.

🎓 Academic Objectives

  • Demonstrate real-world machine learning applications
  • Apply data preprocessing and feature engineering techniques
  • Compare multiple ML algorithms (Logistic Regression, Random Forest, SVM)
  • Build interactive web-based prediction system
  • Address social issues through technology

🔬 Technical Approach

  • Algorithm: Random Forest Classifier (100 estimators)
  • Features: 10 behavioral metrics
  • Evaluation: F1-Score, Accuracy, Precision, Recall
  • Technology: Python, scikit-learn, Flask

⚠️ Important Note

This system is for educational purposes only and should not be used as a clinical diagnostic tool. For professional help with smartphone addiction, please consult qualified healthcare providers.
